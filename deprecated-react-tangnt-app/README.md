# Tangnt

A tool for people whose thoughts naturally branch off into tangents—especially those with ADHD or nonlinear thinking styles. Tangnt provides a dedicated space for "yapping" or brainstorming sessions, helping users capture their rapid, interconnected thoughts and turn them into a process of self-exploration.

## Features

- **Chat-like Interface**: Freeform thought entry with a familiar chat-style interface
- **Dynamic Visualization**: Real-time 2D/3D constellation visualization of your thought connections
- **AI Insights**: Discover hidden connections and insights across your thought history
- **Session Management**: Organize and search through your tangent sessions

## Tech Stack

- **Frontend**: Vite + React + TypeScript + Tailwind CSS
- **Backend**: TBD (likely Supabase)

## Vision

Tangnt helps you explore the intrinsic hidden insights and connections of your thoughts through dedicated brainstorming sessions. Each thought becomes a node in your personal constellation, revealing patterns and connections you might not have noticed otherwise.
