# Tangnt App

A clean, minimal Next.js application.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- Next.js 15.4.1
- React 19.1.0
- TypeScript
- Tailwind CSS v4

## Project Structure

```
src/
├── app/
│   ├── page.tsx (main page)
│   ├── layout.tsx (root layout)
│   └── globals.css (styles)
```

Start building your application by editing `src/app/page.tsx`.
